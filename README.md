# TEFA Canning Polije Web Project

Project web profil perusahaan dan unit Teaching Factory (Tefa) Canning Politeknik Negeri Jember.

## Struktur Folder

```text
tefa-canning-polije/
├── index.html
├── organisasi.html
├── eduwisata.html
├── kemitraan.html
├── formulir-permintaan.html
├── kontak.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/                  <-- Letakkan aset gambar di sini
└── README.md
```

## Cara Menjalankan

1. Ekstrak arsip zip ini.
2. Tambahkan aset gambar yang diperlukan ke dalam folder `img/` (misalnya: `gedung-tefa.jpg`, `sarden-sip.jpg`, `peta-lokasi.jpg`, dll.).
3. Buka `index.html` menggunakan browser atau jalankan melalui local server (Live Server di VS Code).

## Halaman

Setiap bagian utama memiliki file HTML sendiri: `index.html` untuk Home, lalu `organisasi.html`, `eduwisata.html`, `kemitraan.html`, `formulir-permintaan.html`, dan `kontak.html`. Navigasi antarhalaman menggunakan tautan biasa; CSS, JavaScript, serta aset gambar tetap digunakan bersama.
